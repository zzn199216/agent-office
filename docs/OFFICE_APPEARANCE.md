# 办公室场景与可替换形象

Agent Office 0.13.0 的文字和办公室视图共用同一房间、成员与消息。切换视图只改变呈现方式，不重新连接模型，也不会创建新的委托。

## 场景

办公室是矩形房间，入口嵌入左上方的连续墙体。每位成员增加一张独立工位；桌子、座椅、角色、背景和装饰使用独立图层，不将整个办公室烘焙成一张不可扩展的图片。

办公室视图占满顶部导航栏以下的主区域，文字模式的状态行、消息列表、页脚和常驻输入卡在此视图中收起。点击“发消息”或成员可展开共享的浮动输入栏；收起输入栏、切回文字时保留草稿和引用。实际待确认事项提供独立入口，点击后进入文字页原来的确认面板。

背景自动填满可用的矩形视口，工位和角色保持自然比例。默认网格根据窗口宽度排列，成员增加时向右、向下扩展；超出画面的工位可滚动查看，名称和聊天气泡保持可读。关闭“随窗口自动排列”时保留用户选定的一、二或三列。

窗口大小和右侧面板开合时重新排列工位，普通消息刷新保留浏览位置；切换到另一间办公室时显示该房间的场景。空办公室的秘书教程保持正常尺寸。桌面窗口尺寸与位置单独保存在本机 `desktop-window.json`，不改变办公室数据。

新加入的成员从门进入，沿走道走到自己的工位。已在房间里的成员保留位置；普通状态更新和重新切换视图不会重复制造加入事件。实际发言显示为该角色的聊天气泡。点击角色选中该成员，仍可使用下方输入框明确发送给谁。

气泡来自本机保存的真实消息，详细内容可以在文字视图中查看。待机动画只让场景更自然；处理中、信箱待领取、心跳过期和离线分别使用真实状态。空闲角色不会生成虚构的聊天或工作。

使用系统“减少动态效果”时，场景减少或停止装饰动画。视图选择只保存在当前界面，不影响 Grok 群中的成员身份和后端会话。

## 修改成员外观

打开右侧 **成员与资料 → 外观**，选择成员。场景中的“改形象”按钮也可打开同一面板。

| 可替换项 | 用途 |
| --- | --- |
| 品牌形象 / 默认机器人、小人、机器人、精灵 | 默认自动选择可用品牌形象；没有可用完整形象时使用原创非人形机器人和独立身份徽章。旧有明确选择继续保留。 |
| 办公桌 / 懒人沙发 | 同一个成员可以换工位类型；懒人沙发配有笔电。 |
| 角色大小 | 在 65% 到 135% 范围内调整完整角色的显示大小。 |
| 标识颜色 | 修改选中标识与后备形象的主色调；完整角色图片保留原有颜色。 |
| Logo / 头像 | 替换独立身份徽章和文字聊天中的成员头像。 |
| 完整角色形象 | 使用自己的机器人、动物或其他形象；不会将默认头像覆盖在上传角色的脸上。 |
| 恢复默认 | 清除自定义形象，回到该成员的默认预设。 |

点击保存后外观写入本机成员资料，重新打开软件和停止服务后的历史视图均使用同一外观。外观修改不改变 provider、真实后端、成员授权或原生 Grok Bot；Grok 端的头像和名称仍由 Grok 自己管理。

## 自定义图片

用户图片使用 PNG、JPEG 或 WebP。支持透明 PNG/WebP，建议头像为方形、人物为透明背景图片。页面会先缩小到适合场景的尺寸；每份保存的图片最大 128 KiB，最大像素尺寸为 1024 × 1024。图片以本机 JSON 中的 raster data URL 保存，不会上传到外部图床。

程序核对实际图片格式，拒绝脚本、SVG 上传、动画 GIF、任意文件路径或远程图片地址。内置 SVG 素材来自随包公开资源，由项目维护；它与用户上传接口分开。

## 修改房间场景

打开右侧 **场景** 页，或点击办公室中的场景设置按钮。每个房间分别保存配置，修改后点击“保存场景”。

- 布局：默认随窗口自动排列；关闭自动排列后选择固定一、二或三列，并调整工位间距。
- 时间：默认跟随电脑时区，也可输入 IANA 时区，例如 `Asia/Taipei`、`America/New_York`；可手动固定白天或夜晚。
- 背景：调整墙面、地面颜色，显示或隐藏窗户、绿植和时钟，开关环境动画。
- 素材：单独替换背景画、办公桌、懒人沙发、绿植和门；每项可恢复内置素材。

办公室时钟显示指定时区的真实日期和时间。自动光线分为清晨、白天、傍晚和夜间，窗口有轻微环境动态；时间按当地钟点切换，没有使用地理位置计算日出。系统“减少动态效果”、关闭动画或隐藏场景时停止装饰运动，时钟仍按真实时间刷新。停止本机服务后可以查看保存的场景与消息，不会由装饰动画产生模型任务。

场景设置保存在本机数据库的 `office.<roomId>` 中，成员设置保存在 `appearance.<memberId>` 中。恢复场景只清除所选房间的场景偏好，不删除成员、消息、授权或原生会话。专业界面使用 `GET/POST /api/office`；模型的 MCP 通信不附带这些图片，也不增加更改场景的权限。

## 维护内置素材

`web/office.js` 与 `web/office.css` 负责场景行为和样式；`web/assets/office/` 存放独立的桌子、懒人沙发、完整机器人、绿植 PNG，以及内置后备图形和品牌身份标识。默认机器人与家具按用户选定的极简卡通参考图生成；CSS 图形用于后备显示及兼容旧预设。头像、完整角色和家具分别替换各自的图层。

默认身份徽章使用可核验的官方网络形象；豆包使用官网头像，其余使用官方组织 Logo 或产品图标。Qwen 的自动完整角色是根据官方水豚参考图生成的独立卡通改编；其他暂缺可靠完整角色素材的品牌使用原创机器人，保留对应身份徽章。没有匹配或头像文件加载失败时使用项目内置图标。用户保存的自定义图片优先，不会因软件升级被默认图覆盖。默认资源离线可用，不会在运行时联网抓头像。

素材来源与使用说明见 [AVATAR_SOURCES.json](../web/assets/office/AVATAR_SOURCES.json)，设计调研见 [OFFICE_RESEARCH.md](OFFICE_RESEARCH.md)。品牌头像保持原图比例、颜色，仅作为对应成员的身份标记；完整人物和衣服的颜色独立修改。

桌面分发只包含显式公共资源清单，并检查哈希。新增内置素材时，同步更新桌面构建的公共清单和安装校验清单；不能把实例数据、角色授权文件或私有配置复制到 `desktop-web`。用户更换外观无需修改这些素材或安装包。
