- 接入页提供「复制连接人物说明」：不支持自动创建的客户端由用户自己建对话、发一次说明并实际调用 MCP；无需填写房间 ID 或入口卡路径。Qwen 引导明确类型为 StreamableHTTP，不能选 SSE，配置放原生设置而非聊天正文。此前原生 410 错误对应 SSE 选项；用户改成 StreamableHTTP 后本机记录工具发现成功，但模型业务调用尚无证据。

- 用户要求不要随意使用 computer-use；由用户提供当前客户端信息，后续仅在确定用户没有使用电脑时才考虑窗口操作。原生 UI 本轮不继续操作。
- 不把 MCP 工具接通等同于创建或唤醒原生聊天。保留 Codex 等后台会话与 Grok 本机桥接的已有路径；Qwen 消费端由本人发起对话，窗口创建能力需要独立适配和验收。
- 最终验证：561 项测试、JavaScript 检查与 diff 检查通过。0.14.12 EXE 的隔离验证覆盖没有房间时身份仍连接、同一地址/凭据/HTTP 会话在新房间收信与跨后台重启；打包后的持续 stdio 连接回归也通过。本地测试入口为 `release/AgentOffice-0.14.12-windows-x64/AgentOffice.exe`。验证记录在 `output/validation/mcp-continuity-0.14.12.json`，没有操作用户窗口或调用真实模型。

## 注意事项

- 仓库在网络盘 Y: 上，git 和测试都慢。删除文件可能失败，会在 `.git` 里留下 `stale-*` 锁文件，可以直接删掉。
- 在带有 `ANTHROPIC_*` 环境变量的 shell 里，`tests/claude.test.cjs` 会受宿主 Claude 配置影响而失败。跑这组测试前先清掉这些变量。
- 与 Codex 并行开发时，各用一个分支或 worktree，避免互相覆盖。
